# Civilization data

## coastlines.json
Natural Earth 1:110m coastline (https://www.naturalearthdata.com/, public domain), via https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_coastline.geojson. 134 line strings, lon/lat pairs rounded to 0.01°.

## chapters.json
Eighteen chapters of the human story, written for this site. Coordinates are published locations of the sites named;
dates follow the cited sources in each chapter.
